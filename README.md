# 织锦工坊 · 安全巡检与隐患整改台

直接用浏览器打开 `index.html` 即可使用，无需后端；所有数据保存在本机浏览器 localStorage，刷新后全部保留。

## 角色与主流程

1. **管理员**：维护区域、检查项（可停用/启用）、责任人；配置三个等级的整改期限；可在整改单总表中调整隐患等级。
2. **巡检员**：按区域逐项巡检，记录「合格」或「问题」。问题选择等级（一般 / 较重 / 严重）与责任人后自动生成整改单并写明期限。
3. **责任人**：在「我的整改任务」中填写整改说明并提交，状态变为待复核。
4. **巡检员复核**：通过 → 闭环；不通过 → 退回责任人重做，期限从退回时刻重新起算。

## 业务规则

- 同一检查项存在未闭环整改单时，**不能重复开单**，只能查看跟办。
- 待整改/被退回的单子**逾期自动升级**一级（一般 → 较重 → 严重），并按新等级重新起算期限；系统每秒检测，刷新页面也会立即检测。
- 管理员**调整等级时同步重算期限**，并联动区域限制。
- **严重隐患未闭环 → 区域受限**：该区域暂停新开整改单（仍可记录合格）；严重隐患整改并全部复核通过后区域自动恢复。
- **检查项停用不影响已开整改单**：停用后不出现在巡检列表，已开单据照常流转。

## 演示提示

管理员 →「等级期限与规则」页可一键切换为 **3/2/1 分钟短周期**，快速观察逾期自动升级；默认期限为一般 24h / 较重 8h / 严重 2h。
